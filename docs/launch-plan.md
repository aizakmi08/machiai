# Launch Plan

## Positioning

Machiai is not a chess website. It is a floating, bounded waiting room for the new idle state created by AI coding agents.

Tagline:

```text
Chess for people waiting on AI agents.
```

## Demo Script

1. Run `machiai app`.
2. Keep the square overlay beside Codex or Claude.
3. Start an agent through `machiai run --overlay -- ...`.
4. Show the overlay unlocking 3+0 chess.
5. Match into a live game and move pieces by drag/drop.
6. End one agent midgame and show the finished banner.
7. Finish the game, show MMR change, then show next-game lockout.

## Post

```text
I got tired of doomscrolling while Codex was running.

So I built Machiai:
a floating chess overlay for people waiting on AI agents.

Your agent works.
You play 3-minute chess.
When the agent finishes, you get notified.
No next game until another agent is running.
```
